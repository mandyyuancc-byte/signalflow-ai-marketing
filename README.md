# SignalFlow｜AI营销增长诊断台

SignalFlow 是一个面向品牌、公关与营销工作的浏览器端分析工具。它可以读取项目 Brief 与跨平台渠道数据，完成数据审核、指标计算、可视化分析、组合效果评分，并生成下一轮策略与创意假设。

## 在线体验

https://signalflow-ai-marketing.mandyyuancc.chatgpt.site/

## 核心功能

- 支持填写多目标营销 Brief 与项目标签
- 支持 CSV、XLSX、Word、PDF 和常用图片文件
- 自动检查数据条数、缺失值与异常值
- 计算 CPC、CPM、CPV、CPA、CPE、CVR、互动率、点击率、观看率与 ROAS
- 支持柱状图、折线图和饼状图
- 支持平台、内容类型与达人类型的交叉效果分析
- 支持自定义综合评分指标、权重与计分方向
- 根据信息完整度输出案例启发与待验证创意方向

## 使用方式

直接打开 `index.html`，或通过静态网站服务托管仓库根目录。首次体验可点击“载入完整示例”，随后点击“生成AI诊断”。

## 数据说明

上传数据仅在当前浏览器内解析和计算，不会由本项目主动上传至服务器。演示品牌、项目与示例数据均为虚构内容。
